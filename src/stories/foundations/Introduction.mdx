# Grand Moff Tarkit

A React component library built on [shadcn/ui](https://ui.shadcn.com), restyled after the
in-universe displays of the Star Wars films: phosphor-coloured line work on black glass, cut corners,
HUD brackets, scanlines and targeting grids.

Every component keeps the **exact shadcn API**. If you know shadcn, you already know this library;
the shadcn docs remain the reference for props and behaviour. Only the styling changed.

## Install

```bash
npm install grand-mofftarkit   # or pnpm add / yarn add / bun add
```

**Requirements:** React 19 and React DOM 19 (peer dependencies). Everything else the components use
(Radix, Recharts, Sonner…) installs automatically and is shared with your app, so there's never a second copy.

Works with any React setup: Vite, Next.js (App Router and Pages Router), Remix / React Router,
Astro islands, plain webpack. ESM and CommonJS builds and full TypeScript types are included.
Every module is marked `"use client"`, so components can be dropped straight into Next.js Server Components.
Your bundler only includes the components you actually import.

### Styles: pick one

**A. No Tailwind in your app (or you don't want to configure it).** Import the prebuilt stylesheet once at the root:

```tsx
import 'grand-mofftarkit/styles.css'
```

It contains everything the components need, including a small CSS reset. Your own markup can use the
CSS variables (`var(--primary)`, `var(--border)`…) but not Tailwind classes.

**B. Your app uses Tailwind CSS v4.** Replace your `@import "tailwindcss";` with the library's theme,
so your own code can use the same tokens and utilities (`bg-primary`, `text-phosphor`, `chamfer`, `hud-corners`…):

```css
/* app.css */
@import "grand-mofftarkit/tailwind.css";
```

This imports Tailwind for you and scans the library's components, so don't also import `styles.css`.
Note that the theme makes Tailwind's `dark:` variant always active, because the system is dark-only.

### Use

```tsx
import { Button, Card, CardHeader, CardTitle, CardContent } from 'grand-mofftarkit'

export function Reactor() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>Reactor core</CardTitle>
      </CardHeader>
      <CardContent>
        <Button>Engage</Button>
      </CardContent>
    </Card>
  )
}
```

Two providers are needed only if you use the matching components:

| Component        | Wrap your app in    |
| ---------------- | ------------------- |
| `Tooltip`        | `<TooltipProvider>` |
| `toast()` (Sonner) | render `<Toaster />` once |
| `Sidebar`        | `<SidebarProvider>` |

## Pick a console palette

The system is dark-only. Set `data-theme` on `<html>` (or on any element, to theme just that subtree):

```html
<html data-theme="imperial">  <!-- red, the default -->
<html data-theme="blueprint"> <!-- blue technical readouts -->
<html data-theme="rebel">     <!-- amber targeting computers -->
<html data-theme="terminal">  <!-- green CRT -->
```

Use the **paintbrush** in the Storybook toolbar to preview every story in each palette.
See [Foundations/Themes](?path=/docs/foundations-themes--docs) for how a palette is built.

## Adding a component

Components live in `src/lib/components/ui` and are added with the shadcn CLI:

```bash
pnpm dlx shadcn@latest add <component>
```

If the CLI asks to overwrite an existing file, answer **no**: those files carry the custom styling.
The CLI drops in the stock shadcn version. To match the system, apply the same conventions used by the
others: no rounded corners, `shadow-glow` instead of focus rings, uppercase tracked titles in `text-primary`,
and `font-mono` for data. Then add a story in `src/stories/<group>/` and export it from `src/lib/index.ts`.
